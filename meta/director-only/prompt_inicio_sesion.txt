PROMPT DE INICIO DE SESIÓN — Z.ai v1.1
========================================

Este prompt se usa al iniciar una nueva sesión con un agente Z.ai o al reiniciar tras pérdida de contexto.

---

INSTRUCCIONES PARA EL AGENTE:

1. Lee los archivos de estrategia de tu repo correspondiente:
   - Agentes APA, MB, CZAI → Repo operativo: https://github.com/Juank6507/estrategia-agentes-zai
   - Agente Estrategia → Repo completo local: C:\Python\Proyectos\estrategia

2. Archivos obligatorios a leer:
   - agent-context/contrato.md
   - agent-context/dcepi.md
   - agent-context/comunicacion.md
   - agent-context/identidad.md
   - agent-context/proyecto.md
   - agent-context/entorno.md

3. Internaliza las reglas:
   - 7 Invariantes absolutos (I1–I7)
   - 16 Reglas Preferidas (R1–R16)
   - Metodología DCEPI (5 fases)
   - Protocolos de comunicación
   - Sentencia de control: [FASE: X | Estrategia: activa]

4. Lee el worklog del proyecto correspondiente para reconstruir contexto.

5. Emite tu primera respuesta con sentencia de control:
   [FASE: D | Estrategia: activa]

6. Comienza con DIAGNÓSTICO de la tarea actual.

SENTENCIA DE CONTROL:
Toda respuesta DEBE iniciar con: [FASE: X | Estrategia: activa]
Si no la emites, el Director asume pérdida de contexto.

---

PROTOCOLO DE RECUPERACIÓN:
Si el Director indica que perdiste contexto:
1. Leer worklog
2. Leer archivos de estrategia
3. Re-internalizar invariantes
4. Re-internalizar sentencia de control
5. Emitir confirmación de recuperación
6. Continuar con sentencia de control

Fallback: El Director reinicia la sesión con este prompt.
